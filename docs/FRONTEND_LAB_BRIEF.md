# 19. YOUR PROFESSIONAL FRONTEND WORKFLOW

For all future MAKENDLESS frontend tasks, follow:

**RESEARCH → CONCEPT → PROTOTYPE → RUN → INSPECT → CRITIQUE → REFINE → TEST → INTEGRATE**

RESEARCH:
Verify relevant APIs and design techniques.

CONCEPT:
Define the purpose and visual direction.

PROTOTYPE:
Implement an isolated working example where the technique is complex.

RUN:
Launch the example.

INSPECT:
View the actual browser output.

CRITIQUE:
Identify weak design decisions.

REFINE:
Improve the implementation.

TEST:
Verify usability, accessibility and performance.

INTEGRATE:
Add successful patterns to the authorized website codebase when appropriate.

Do not copy an experimental component directly into production if it has failed testing.

Do not treat a visually attractive screenshot as proof of working functionality.
