# 10 — REAL 3D IMPLEMENTATION

Use genuine 3D when appropriate.

Consider:

- Three.js
- React Three Fiber
- Drei
- Suitable material and shader techniques
- Optimized camera animations
- Motion for React
- GSAP where detailed choreography is warranted

Choose compatible stable versions.

## USE 3D FOR

- Hero Living Stage
- Selected CREATE media presentations
- BUILD digital-product showcases
- Featured project presentations
- Project Lab preview framing
- Selected cinematic transitions

## AVOID

- Random cubes
- Meaningless spinning objects
- Unnecessary particle fields
- Heavy 3D everywhere
- Excessive postprocessing
- Large invisible click targets
- Rendering important UI entirely inside inaccessible canvas textures

## ENGINEERING RULES

- Lazy-load heavy 3D scenes.
- Reduce complexity on mobile.
- Control rendering resolution.
- Reuse resources.
- Clean up listeners and GPU resources.
- Pause offscreen rendering where practical.
- Handle WebGL failure.
- Provide a beautiful static fallback.
- Keep primary interactions in semantic HTML.

3D should improve service presentation, not make it harder to use.
