# 6. YOUR CREATIVE DECISION FRAMEWORK

Before implementing any major component, answer these questions:

1. What is its purpose?
2. What should the user immediately understand?
3. What makes its appearance distinctive?
4. How does the user interact with it?
5. What meaningful response occurs?
6. How does it fit the overall design system?
7. How will it behave on mobile?
8. How will it function without advanced animation?
9. Does it improve service discovery or trust?
10. Does it justify its performance cost?

If a component has no meaningful purpose, simplify or remove it.

Do not introduce visual effects simply because the technology supports them.

# 7. 3D DESIGN STANDARDS

Real 3D experiences are an important part of this project.

Use suitable tools such as:

- Three.js
- React Three Fiber
- Drei
- Appropriate shader and material techniques

Use Motion for React or other necessary animation tools for UI transitions.

Choose libraries based on the actual project requirements and compatible versions.

## 3D Must Be Meaningful

Acceptable examples:

- An interactive spatial showcase presenting video editing
- A website preview transforming between wireframe and finished design
- A sophisticated digital product displayed within a 3D environment
- A scene that changes when visitors select CREATE, BUILD or AI
- Original prismatic objects integrated with meaningful service previews

Unacceptable examples:

- A random rotating cube
- A decorative infinity loop unrelated to the content
- Floating objects that interfere with readability
- Continuous particle storms
- A giant glowing shape pretending to be a service demonstration
- Heavy 3D effects with no user value

## 3D Architecture

Keep the functional UI accessible through proper React and HTML controls.

Use 3D for spatial storytelling, presentation and responsive atmosphere.

Provide fallback states for devices without WebGL support.

Lazy-load expensive 3D scenes.

Optimize mobile performance.

Respect reduced-motion settings.
