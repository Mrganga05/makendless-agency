## Original work and scope

The arch, steps, runner and disc composition is original inline SVG. The exhibition lamp, vessel and chair are original CSS illustrations. FOLD is an expressly fictional exhibition concept. No reference-site screenshot, layout, brand asset, animation source, client result or proprietary media was copied.

There are no external service calls. The video demonstration does not encode or process a file. The website form produces a local draft. The workflow uses disclosed ordered substring rules and cannot send a message. Both palettes use the lab's shared tokens.

## Implementation findings

- Preset buttons make a comparison useful without precise dragging; independent caption and crop controls provide visible creative differences.
- Reusing real site content in the wireframe mode makes the comparison about design quality while preserving comprehension.
- Keeping derived workflow values out of state avoids a stale category paired with a newly edited inquiry.
- Native `<output>` has an implicit status role. The automatically advancing film clock uses a decorative span instead; the focused position range supplies accessible time information. This avoids an unintended repeated live announcement.
- A small working example can demonstrate service understanding without suggesting real processing or inventing client outcomes.
