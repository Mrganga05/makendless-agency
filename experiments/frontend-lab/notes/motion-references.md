# Motion and composition research notes

Accessed through web research on 2026-11-13. Only primary technical documentation informed these experiments. No external agency layout, portfolio project, photograph, film, client identity or proprietary artwork was copied. Vector ribbons and sculptural forms are original code compositions.

| Reference                                                                                                                        | What was examined                                                 | Applied / rejected                                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| [Motion React animation](https://motion.dev/docs/react-animation)                                                                | State targets, variants, keyframes and entrance/exit concepts.    | Applied state-first design. Deferred Motion installation: no complex shared layout or exit orchestration is required by this prototype. |
| [GSAP Timeline](https://gsap.com/docs/v3/GSAP/Timeline/)                                                                         | Timeline composition, sequencing positions and playback controls. | Applied one shared playhead with controlled phases. Deferred GSAP installation until sequence complexity justifies it.                  |
| [Using the Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API/Using_the_Web_Animations_API) | Native keyframes and animation lifecycle.                         | Implemented a bounded, cancellable scene reveal with a static unsupported fallback.                                                     |
| [SVG pathLength](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/pathLength)                                | Normalized path-distance calculations.                            | Implemented directly derived SVG dash progress; no frame-by-frame DOM path measurement.                                                 |
| [CSS clip-path](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/clip-path)                                 | Visible regions and inset shapes.                                 | Implemented image/heading reveal; reduced motion keeps content exposed.                                                                 |
| [Intersection Observer API](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)                          | Asynchronous viewport intersection, visibility-driven work.       | Implemented three observed chapters and offscreen playback suspension. Native chapter controls remain available.                        |

The resulting studies are `src/MotionLab.tsx` / `motion.css` and `src/SectionLab.tsx` / `sections.css`. Full decisions, timings, fallback contract and evidence limits are in the [motion graphics system](../../../docs/MOTION_GRAPHICS_SYSTEM.md).

We compared documentation and implementation fit, not runtime benchmarks between libraries. Nine scoped DOM tests passed after implementation; they are not browser visual approval. Browser, mobile and GPU results belong in the shared QA evidence once genuinely observed.
