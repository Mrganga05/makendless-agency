# Isolated frontend experiments

Read ../../docs/FRONTEND_LAB_BRIEF.md and the relevant guides under ../../docs.

- This directory is a separate Vite application using the parent checkout's installed dependencies. Do not import production src components or styles. Do not write the production build output or publicly deploy the lab.
- All new prototypes are proposals. Keep Syne, MAKENDLESS, CREATE / BUILD / GROW and beta labeling accurate. Original vector/concept media only; no fictitious client proof, pricing or AI delivery.
- Use settings.tsx for reduced motion, theme and forced HTML fallback. Keep native controls outside canvas, finite animation, visible static content and full lifecycle cleanup.
- Run local typecheck/lint/tests/build from this directory. Tests with a mocked renderer are not GPU inspection. Record genuine browser evidence or the exact blocker.
- No prototype is accepted for production based on compilation or a screenshot alone. Compare using the visual checklist and interaction evidence first.
